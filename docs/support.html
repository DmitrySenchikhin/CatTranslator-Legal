Support

Help for Cat Companion on iOS 18+.

Common issues

  • Microphone denied — Open Settings → Cat Companion → Microphone and allow access.
  • Try again — Record one clear meow for 1–3 seconds in a quieter room.
  • Purchases — Use Restore Purchases in Settings. Confirm you are signed into the same Apple ID used for the purchase.
  • Delete a cat — Profile → open the cat → Delete cat. Personal Teach AI data for that cat is removed from the device.
